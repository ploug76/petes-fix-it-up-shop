# Start here

Pete's Fix It Up Shop stays on this device. It does not upload a report.

1. Open the app. On a phone, add it to the home screen.
2. Tap **Open practice file** on Intake before you use a real report. The practice file is made-up.
3. Tap **PDF or photo**. Pick a PDF, or a JPG, PNG, or WEBP of the report. Text PDFs are read directly. Photos and scanned PDFs are read on this device. You can also paste the text.
4. If the picture is handwriting, very blurry, or too dark, the app will say it could not read it. Paste the text or type the accounts.
5. Findings lists only contradictions. Letters are drafts that show why those Metro 2 fields cannot all be true at once. The second letter asks how they verified. It does not repeat the first one.
6. Check every date against the report. This is not legal advice.

Built for Peter.
