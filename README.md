# Pete's Fix It Up Shop

Offline credit-report accuracy checker. Load a report (PDF or text), find date and balance contradictions, and draft dispute letters. Everything stays in your browser on this device. No uploads. No analytics.

## Use it

- Live app: https://ploug76.github.io/petes-fix-it-up-shop/
- Or open `index.html` / `Petes-Fix-It-Up-Shop.html` in a desktop browser.

## Install as an app

1. Open the live link in Chrome (Android / Windows) or Safari (iPhone).
2. Android/Windows: browser menu → Install app / Add to Home screen.
3. iPhone: Share → Add to Home Screen.

## Practice data

Use **Open practice file** on the Intake tab first. That file is made-up. Letters are drafts — check every date against your report. Not legal advice.
